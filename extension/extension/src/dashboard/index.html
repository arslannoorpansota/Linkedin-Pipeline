How this works
  1. Open a Sales Navigator search in another tab. Keep this page open.
  2. Press Start collecting. It reads through the result pages for you and stops on its own at the end, or if LinkedIn asks it to slow down.
  3. Press Download leads when it finishes.
  4. Then run ./run.sh in your terminal — it takes it from there.
