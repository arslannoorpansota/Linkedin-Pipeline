- **Time:** —
- **Agent:** Infra / Ops
- **Target:** `ElectroCom Linkedin Pipeline` sheet (all tabs) + `scripts/format_sheet.py`, `scripts/sync_reports_to_sheet.py`

- **Output:**

  **1. Fixed the broken daily sync (found while working, not reported).**
  `sync_reports_to_sheet.py` loaded the cached token with `Credentials.from_authorized_user_file(TOKEN_FILE, SCOPES)`. The saved token was only ever granted `spreadsheets`, but `SCOPES` also lists `drive.file` — so every refresh asked Google for a scope the user never consented to and was rejected with `invalid_scope`. **The cron sync has been dead since 2026-08-17** (see `scripts/sync.log`). Now the token is loaded with the scopes it was actually granted, and a `RefreshError` falls through to a fresh consent flow instead of crashing. `drive.file` is only needed to *create* a spreadsheet, and ours already exists, so no re-consent is required. Verified working.

  **2. Rewrote `format_sheet.py` as a full design system.** The old version was styling a stale 49-column layout; the live sheet has **57 columns** (blank col A + 8 columns added since: Lead Name … Cadence Stage). It now reads the **live header row** from each tab, so late-added columns are styled and future ones will be too.
  - **Section-tinted header bar** — 10 column blocks (Identity / Contact / Qualification / Outreach / Response / Follow-up / Deal / Admin / Rating / Cadence), each a different dark hue at matched darkness, so you can tell where you are while scrolling across 57 columns. Verified landing on exact boundaries.
  - **Frozen header row + first 5 columns** — name/company stay put when scrolling right.
  - **Status chips covering all 21 real values**, not just the 13 canonical ones. The old map missed the dominant ones — `Skip` alone is 1,044 rows — plus the whole `T2/T3/T4 sent` cadence family and `Connected - follow-up sent`.
  - **Cadence Stage chips** — OVERDUE red / REPLIED green / PARK grey / "due …" amber. OVERDUE is ordered first because Sheets' `TEXT_CONTAINS` is case-insensitive, so `OVERDUE T3` also matches "due".
  - **Score gradients** (red→amber→green) on Lead Score, Profile Rating, Company Rating; **inverted** on Days Since Last Touch, where a long silence is the bad end.
  - **Status-aware overdue highlighting on Next Action Date** — red overdue / orange due-today / amber due-within-3-days, suppressed on dead statuses so 1,000+ skipped rows don't light up red. Live counts at time of writing: **136 overdue, 1 due today, 2 due within 3 days.**
  - **Dead rows greyed out** (Skip / Not Relevant / Closed / Lost / On Hold — 1,255 rows) via a text-colour-only rule, so live leads pop without fighting the zebra banding.
  - **Outreach-copy chips on columns X / Y / Z** (`DM Content`, `Email Subject`, `Email Content`) — green where copy is written, grey where empty. You can't read a full DM body in a cell, so these are chipped on presence instead: scan the three columns to see which leads actually have a draft ready vs. still need one.
  - **Dropdowns + checkboxes** on 12 categorical columns, each unioned with the values already in that column so historical entries aren't flagged as invalid. Columns with >40 variants (Industry, Lead Source) are skipped — a dropdown there would be noise.
  - Zebra banding, hairline grid, per-column widths, date/currency/number formats, tuned row height.
  - **Activity Log** and **Cadence Reminders** tabs styled to match (Cadence Reminders keeps its banner-row-1 / header-row-3 layout, which `cadence_reminder.py` rewrites daily — formatting survives because it clears values, not formats).
  - New **Legend** tab documenting the whole colour system.

- **Notes / gotchas found:**
  - The old script's `date_rules` used `DATE_BEFORE`/`DATE_EQ`, which **silently never fired** on the oldest rows: dates are written `RAW`, so early rows are text, not date serials. Sheet is mixed today (678 real dates, 10 ISO-text stragglers, 731 blank). The new rules use a custom formula handling both.
  - Nothing here writes to a data cell — the redesign is purely presentational. Only the new Legend tab has content, and it is generated.
