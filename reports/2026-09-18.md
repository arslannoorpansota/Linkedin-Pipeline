### 2026-09-18 — INFRA / OPS: Pipeline hang — ACTUAL root cause found (161.8 MB of data validation)

The earlier fix this session (phantom rows + CF ranges + cadence freeze) did **not**
resolve the hang. User reported it persisting. Deeper audit of cell-level metadata
found the real cause, which was never row count.

**Root cause: 161.8 MB of `dataValidation` on the Pipeline tab.**

Four **freeform text** columns each carried a **500-option dropdown**, stamped onto 403
cells apiece. Every one of those cells stored its own full copy of all 500 options:

| Col | Header | Avg option length | Payload |
|---|---|---|---|
| BB | Rating Reason | 273 chars | 60.3 MB |
| AW | Internal Notes | 241 chars | 54.0 MB |
| S | Hook / Why Outreach | 124 chars | 30.4 MB |
| G | Location | 23 chars | 9.9 MB |

The "options" were the columns' own existing contents — full rating-reason paragraphs,
internal notes, hook text. Classic result of a "create dropdown from existing values"
action run on a freeform column. The browser had to parse and hold all 162 MB to paint
the grid, which is why the freeze was worst deep in the sheet and near the wide
text columns.

**Why it was NOT the rows:** 2,400 × 62 ≈ 149k cells is unremarkable for Sheets.
Validation attaches to *cells*, so the user's proposed tab-split would have carried the
bloat into both tabs and broken dedupe, `pipeline_health.py` and every column reference
in `agents/`. Split was declined for that reason and the cause fixed instead.

**User's intent, preserved:** the dropdowns were added to stop long text overflowing
into neighbouring columns — a real problem, wrong mechanism. Replaced with:

- `wrapStrategy: CLIP` + top vertical align on G/S/AW/BB (all four were already CLIP,
  so removing validation caused no overflow regression)
- Per-column background tints + a right border, so each freeform column reads as its
  own lane: G blue, S green, AW amber, BB violet

**Result: 161.8 MB → 14.4 MB (-91%).**

**Verified:** no data touched — G 2320, S 1915, AW 2091, BB 2244, C 2325, Cadence Note 352
non-empty, all unchanged. All 11 legitimate pick-list dropdowns intact
(K, M, P, Q, T, U, W, AA, AD, AS, AV).

**Watch for recurrence:** do not use "dropdown from a column's own values" on G, S, AW,
BB or any freeform column. To contain long text use CLIP + a set column width. Remaining
14.4 MB is normal pick-list validation on AD/T/P/M/U/Q and is not a concern.
